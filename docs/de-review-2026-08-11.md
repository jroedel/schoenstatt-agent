# German review — the 55 rows written on 2026-08-11

German reached **0 untranslated** on production at 12:47 UTC, out of 1,515 live rows, and then
moved again — seven more rows arrived at 12:49 and were translated too (§6), and two retirements
un-retired themselves. See [`close-2026-08-11.md`](close-2026-08-11.md).

This is the 16 of that day's 55 German writes where a native German speaker settles something.

German is the language where this repository is least able to check itself, for the reason
[`data/style/de.md`](../data/style/de.md) states: **German is usually the original, not a
translation.** The charism's vocabulary was coined in German, so where a German row differs
from the English key the German is more likely to be right than the key is. Two of that
document's four standing open questions were unavoidable in this pass and are the first two
entries here.

**Every phrase id is a production id.** Resolve by source string, never by carrying an id
between environments.

Corrections are recoverable since the 2026-08-11 deploy — `GET /api/v3/phrases/{id}/history`
returns the exact previous text — so replacing anything here is an ordinary write.

### 1.2 `Sie` in shrine notices addressed to pilgrims — ANSWERED 2026-08-11

*phrase ids 7285, 7468, 7198, 7196, 7222, 7223, 7062, 7090, 7053, 7168, 6951, 6954*

**The maintainer: "Let's be consistent with du over Sie. I hope it goes with more of the youthful
spirit of the site."** Settled the same day, and settled in Italian's favour — the divergence
this entry was raised about is gone rather than merely decided.

**61 rows were converted**, so nothing in this pass's German still needs a register answer.
7198 now reads `… Frag einfach direkt die Anbetungsschwestern. Meist nehmen sie sich die Zeit
und zeigen dir — besonders als Pilger ;-) — ihr Heiligtum. Klopf einfach an ihre Tür und frag.`

Two things a German reader should still glance at, because the conversion made choices:

- **Verb forms in the shorter imperatives.** `Frag`/`Klopf`/`Fahr`/`Ruf` were used rather than
  `Frage`/`Klopfe`/`Fahre`/`Rufe`. The clipped form is the more colloquial and fits the *youthful
  spirit* the decision names; the `-e` form is a little more neutral. It is consistent across all
  61 rows, so changing it is one sweep, not a hunt.
- **`Guten Tag %s,` became `Hallo %s,`** in the registration email (6755). A greeting carries
  register too, and the newer sign-in email (12826) already said `Hallo` — but this is the one
  change that replaced a word rather than converting a pronoun.

Recorded in [`data/style/de.md`](../data/style/de.md), including the **four rows deliberately not
converted** because their `Sie` means *it* or *she* rather than *you* (6427 the library, 7086 the
mission trip, 6989 the shrine, 6987 Mary), and 6573 which was converted only in its first half.

**Both of this document's §1 house questions are now answered, and German has no open ones left.**

## 2. Charism vocabulary used in prose for the first time

### 2.1 `Bildstock` for a wayside shrine — four records

*phrase ids 6987, 6988, 7453, 6970*

`data/glossary/de.yaml` gives `Bildstock`, and this pass is the first use of it in running
devotional prose rather than in a label.

**Written (6987):** `Auch dieser Bildstock entstand durch Pater Juan de Dios, Jünger Jesu. Er
steht am Gehweg der Pfarrei Santa Teresa de Jesús in der Stadt Garín, …`

A `Bildstock` in German usage is typically a pillar or niche with an image; several of these
records describe something closer to a small open chapel with an altar and a bell. If the
movement's German for these Latin-American *ermitas* is `Wegkapelle` or the Spanish loan, four
rows change.

### 2.2 `Einheitskreuz` and `Gnadenkapital`

*phrase ids 6988, 6989*

**Written (6988):** `… Er symbolisiert ein Schönstatt-Heiligtum: Das Bild wird vom
Einheitskreuz begleitet, von dem 7 Strahlen radial ausgehen, die die Gaben des Heiligen Geistes
symbolisieren; rechts eine Pflugscheibe zum Verbrennen des Gnadenkapitals und links ein
Blumentopf, der das Leben und die irdische Hoffnung symbolisiert.`

`Gnadenkapital` is in the glossary and is safe. `Einheitskreuz` is **not** — it was chosen for
the Unity Cross because that is the compound the movement uses, but no source in `data/` attests
it. If it is `Kreuz der Einheit`, one row changes and the glossary gains an entry.

`Pflugscheibe` for the Spanish `disco de arado` is a literal rendering of a farm implement used
as a brazier. A German reader may need `Pflugschar`.

### 2.3 `Anbetungsschwestern`

*phrase id 7198*

Taken from the site's own row 14180, where `Adoration Sisters of Mary` is already
`Anbetungsschwestern`. Following an existing row rather than inventing, so this is probably
right; noted so the reviewer knows it was not guessed.

## 3. Where the source string is German

### 3.1 The Vienna directions — the `de` row repairs the key

*phrase ids 7222, 7223 · `Schoenstatt` · route `association-edit` · source: German*

The key is German, and its German row was empty. So the German written here is **the key with
its slips repaired** rather than the key copied verbatim:

- the key's English tail `(If you take the bus 38A direction 'Wagenwiese', it is only half way…)`
  is rendered in German, since a German row should not end in English;
- `Schönstattzentrum` → `Schönstatt-Zentrum`, matching the style guide's hyphenation rule;
- 7223's appended `english:` block becomes a `deutsch:` block, mirroring what the Portuguese row
  did with `português:`.

**The alternative was writing the key verbatim**, which is what a strict reading of "do not
improve what is merely not your preference" would give. The judgement was that an empty German
row for a German key is a gap to fill, not a translation to preserve — but a reviewer may
prefer the untouched original, and if so both rows revert to the key text.

### 3.2 The Budapest description — two slips repaired

*phrase ids 9701, 9702 · source: German*

**Written:** `Das Heiligtum wurde geschlossen. Der Altar des Heiligtums wurde der ungarischen
Schönstatt-Bewegung für ein zukünftiges Heiligtum in Budapest geschenkt. Derzeit befindet er
sich im Haus der Schönstatt-Jugend in Budapest.`

Two repairs against the key: `Aktuell befindet sich in dem Haus` was missing its subject (`es`
or `er`), and `wurde für … geschenkt` becomes the dative `wurde der … geschenkt`.

**9701 and 9702 differ only in `ein zukünftigen` against `ein zukünftiges`** — the same
description before and after somebody fixed the adjective ending. Both now carry the same
German. One of the two rows is superseded and should probably be retired, but which one depends
on the association record and this repository cannot see it. Not retired for that reason:
retiring the live half would remove a real description.

## 4. The new translation-history screen

Six strings, translated into it/de/es/pt together on the day they shipped. Two are structural
choices made identically across all four, so changing one changes all four.

### 4.1 `Replaced` → `Ersetzt am`

*phrase id 17228 · `JTranslate` · route `jtranslate/phrase/edit`*

`Replaced` heads a column of timestamps — read out of
`module/JTranslate/view/j-translate/j-translate/edit.phtml`, where it sits beside `Language`,
`Previous text` and `Note`. Hence *ersetzt am* rather than a bare participle. The English is
bare; if the column ever shows something other than a date this is wrong.

### 4.2 `Note` → `Anmerkung`

*phrase id 17227*

`Anmerkung` rather than `Notiz`, because the column holds a translator's stated **reason** for
replacing a translation, not a jotted note. If German interfaces here want `Begründung`, say so.

### 4.3 The long help block

*phrase id 17224*

**Written:** `Der Text, den Schreibvorgänge auf dieser Phrase ersetzt haben, neueste zuerst.
Nichts davon wird von der Website noch ausgegeben — es wird aufbewahrt, damit eine Änderung
rückgängig gemacht werden kann und damit der Grund für eine Änderung die Person überdauert, die
sie vorgenommen hat.`

`Schreibvorgänge auf dieser Phrase` is doing what the awkward English `What writing to this
phrase has replaced` does, and neither is graceful. This is the longest new interface string in
German and the one most likely to want rewriting rather than correcting.

### The `du` sixty-one

`Sie` → `du` across 61 rows. The mechanics are in
[`data/style/de.md`](../data/style/de.md); what matters for review is what the conversion had to
get right and could have got wrong.

**Five rows where a `Sie` is not address.** These are the reason it was done row by row rather
than with a regex, and a reviewer checking one thing should check these:

| id | left as it was | because `Sie` is |
|---|---|---|
| 6427 | `Sie enthält außerdem eine gute Auswahl` | the library |
| 7086 | `Sie wird von Mitgliedern … organisiert` | die Missionsfahrt |
| 6989 | `Sie wurde am 30. Mai 1998 … gesegnet` | the shrine |
| 6987 | `Sie ist da, um sie zu hören` | Mary |
| 6573 | `Sie wird auf die nächsten … Etiketten übernommen` | the call number — this row's *first* `Sie` was converted |

**Three judgement calls inside the conversion**, each consistent across all 61 rows so that
changing one's mind is a single sweep:

1. **Clipped imperatives** — `Frag`, `Klopf`, `Fahr`, `Ruf`, `Sag`, `Gib`, `Nimm`, `Vergib`
   rather than `Frage`, `Klopfe`, `Fahre`, `Rufe`. More colloquial, which is what the decision
   asked for; `-e` would be more neutral.
2. **`Guten Tag %s,` → `Hallo %s,`** (6755) — the only word replaced rather than converted, on
   the grounds that a greeting carries register and 12826 already said `Hallo`.
3. **Record prose was converted too**, so a shrine's German notice now departs from the register
   its own author wrote in formal Spanish or German. That is deliberate: it makes German agree
   with Italian, which was the point of §1.2.

Verified after writing: **0 formal markers survive** anywhere in the German rows except the five
above, every placeholder and HTML tag is byte-identical to before, and `Hast du Fotos` renders on
`/de/shrines` where `Haben Sie Fotos` used to.
